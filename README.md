# 미니 노션

내 컴퓨터를 작은 서버로 삼아, 같은 와이파이의 팀원이 함께 글을 쓰고 찾는 메모장입니다.

## 준비
- Node 24 이상
- 처음 한 번: `npm install`

## 팀원과 함께 쓰기
```bash
npm run build   # 처음 한 번, 그리고 코드를 고친 뒤
npm start       # 켜기 (끄기: Ctrl + C)
```
- 내 컴퓨터: http://localhost:3000
- 팀원: `http://내컴퓨터주소:3000`
  - 내 컴퓨터 주소는 맥 터미널에서 `ipconfig getifaddr en0` 으로 확인합니다 (예: 192.168.0.10)
- 팀원이 접속하지 못하면: 같은 와이파이인지, 맥 방화벽에서 node 접속을 허용했는지 확인합니다. 와이파이에 따라 기기끼리의 접속이 막혀 있을 수 있습니다.

## 고치면서 보기 (내 컴퓨터에서만 접속)
```bash
npm run dev
```

## 데이터
- 글과 계정은 `data/notion.db*` 파일에 저장됩니다 (git 에 올라가지 않습니다).
- 백업: 서버를 끈 뒤 `data` 폴더를 통째로 복사합니다.

## 주의
- 내 컴퓨터가 꺼지거나 잠들면 팀원은 접속할 수 없습니다.
- 로그인하지 않아도 들어올 수 있어, 같은 와이파이에서 주소를 아는 사람은 글을 보고 지울 수 있습니다. 카페 같은 공용 와이파이에서는 켜지 마세요.
- 연결이 암호화되지 않으므로 다른 곳에서 쓰는 비밀번호는 쓰지 마세요.
- 지운 글은 되살릴 수 없습니다. 비밀번호 다시 정하기 기능은 없습니다.
